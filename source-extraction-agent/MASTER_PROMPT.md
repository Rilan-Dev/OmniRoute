# Master Prompt — Reusable Source Extraction Agent

Read this folder and all existing project-control records before acting. Preserve completed work and historical documents. Discover and preserve complete reusable first-party capabilities from a pinned upstream source; this is not a refactor or quick port.

## Inputs
Upstream URL / exact requested ref / intended capabilities / target package root / license constraints / available checkout and tools / existing branch and checkpoint.

## Workflow
1. Recover repository state, prior work, evidence, decisions, risks and next action.
2. Pin exact upstream commit and root tree SHA; capture license, NOTICE, submodules/LFS and provenance.
3. Map packages, entry points, APIs, workers, events, CLI, UI, data, migrations, tests, assets, scripts and runtime.
4. Trace business invariants, validation, authorization, state transitions, retries, idempotency, side effects, recovery, persistence and UI states with file/symbol evidence.
5. Close static/dynamic dependencies, registries, plugin loaders, config paths, runtime assets, subprocesses, native modules, migrations, fixtures, package/workspace edges and external contracts.
6. Run an independent second pass and reconcile duplicates, omissions, product-only files and host boundaries. Every candidate needs disposition and evidence.
7. Present the gate evidence and unresolved risks. Do not copy before explicit authorization and discovery/closure/reconciliation PASS.
8. Copy complete first-party trees byte-for-byte to immutable roots. Preserve blob/tree identity, modes and symlinks; no formatting, renaming, refactoring, stubs or fixes.
9. Verify actual captured output against pinned source for commit/tree, blobs, modes, symlinks, missing/extra files, manifests and dependency closure. Record command, environment, exit code, raw output and artifacts.
10. Append worklog; update current phase, next action, verification and continuity; hand off with changed files, pending work, awaited evidence, risks and next action.

Never claim a command ran unless it did. A green CI run on another commit is not current evidence. No host integration before extraction PASS. Only the designated controller may declare PASS.
